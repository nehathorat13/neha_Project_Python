XYNTARA MANUAL TEST CASES
=========================

Master CSV: Xyntara_Manual_Test_Cases_All_Roles_1200.csv (1,200 cases)
Separate role CSVs: 300 cases each for Recruiter, Employer, Administrator, Candidate.

Important scope note:
- Xyntara's public website describes ATS/recruitment features including applicant tracking,
  resume parsing, screening, interview management, sourcing, job requisitions, integrations,
  customization, and performance reporting.
- Admin and candidate account portals/permissions are not confirmed by the public pages reviewed.
  Cases for these areas are marked as assumptions/account-dependent and should be validated
  with the product owner or through an authorized test account before execution.
- This is a generated manual test design, not evidence that the tests have been executed.
- Use synthetic data and approved test accounts. Do not use real candidate personal data.
- CSV includes ActualResult, Status, DefectID, and TesterComments columns for execution tracking.
